# 部署文档

## 一、环境要求

| 项目 | 最低要求 | 推荐 |
|---|---|---|
| CPU | 2 核 | 4 核及以上（转码需要） |
| 内存 | 4 GB | 8 GB |
| 磁盘 | 20 GB | 100 GB+（媒体中转缓存） |
| 系统 | Linux（Debian/Ubuntu/CentOS 均可） | Ubuntu 22.04 |
| Docker | 20.10+ | 最新版 |
| Docker Compose | v2（`docker compose`） | 最新版 |

> 若不需要视频转码，2 核 2G 也能跑起来；转码功能会显著消耗 CPU。

## 二、快速部署

### 1. 准备目录

```bash
mkdir -p /opt/littlescholar && cd /opt/littlescholar
# 把项目文件放进来
```

目录结构应为：

```
littlescholar/
├── docker-compose.yml
├── .env
├── backend/
│   ├── Dockerfile
│   ├── go.mod
│   ├── config.yaml
│   ├── cmd/
│   └── internal/
├── frontend-admin/
│   ├── Dockerfile
│   ├── nginx.conf
│   ├── package.json
│   └── src/
└── data/          # 会自动创建
```

### 2. 配置环境变量

```bash
cp .env.example .env
vi .env
```

**必须修改的项**（否则有安全风险）：

```bash
# 生成随机密钥
openssl rand -hex 32
```

- `JWT_SECRET` → 填上面生成的随机串
- `COOKIE_ENCRYPT_KEY` → 再生成一个填进去
- `DB_PASSWORD` → 改成强密码
- `ADMIN_PASSWORD` → 改成你自己的密码

### 3. 启动

```bash
docker compose up -d --build
```

首次构建需要下载依赖，耗时约 3-10 分钟。

### 4. 查看状态

```bash
docker compose ps
docker compose logs -f core-server
```

### 5. 访问

| 入口 | 地址 | 说明 |
|---|---|---|
| 管理后台 | `http://服务器IP:8090` | 用 `.env` 里的管理员账号登录 |
| 后端 API | `http://服务器IP:8080/api/health` | 健康检查 |

## 三、配置 PanSou（资源搜索）

PanSou 已包含在编排中，默认通过容器网络互通（`http://pansou:8888`）。

**如果需要启用 PanSou 的认证**：

1. 编辑 `docker-compose.yml`，取消 `pansou` 服务的注释：

```yaml
pansou:
  environment:
    AUTH_ENABLED: "true"
    AUTH_USERS: "admin:your_pansou_password"
```

2. 重启并配置后端：

```bash
docker compose up -d pansou
```

3. 登录后台 → 「系统设置」→ 填 `PanSou Token`（通过 PanSou 的 `/api/auth/login` 获取）。

**如果需要代理访问 Telegram**（国内服务器常见）：

```yaml
pansou:
  environment:
    PROXY: "socks5://your-proxy:1080"
```

> PanSou 的搜索源包含 Telegram 频道，国内服务器直连可能失败，建议配置代理。

## 四、绑定网盘账号

登录后台后：

1. 进入「网盘账号」页面
2. 点击「添加账号」
3. **扫码方式**：选择网盘 → 生成二维码 → 用手机 App 扫码确认
4. **手动方式**：粘贴浏览器 Cookie

### 各网盘 Cookie 获取方式

**夸克网盘**
```
1. 浏览器登录 https://pan.quark.cn
2. F12 → Network → 刷新页面 → 点任意请求 → Request Headers
3. 复制完整 Cookie（包含 __puus、__uid 等）
```

**百度网盘**
```
1. 登录 https://pan.baidu.com
2. 需要 BDUSS（最重要）和 STOKEN
3. 手动方式：Cookie 字段填 BDUSS=xxx
4. Extra 字段填 {"STOKEN": "xxx"}
```

**UC 网盘** / **天翼网盘**
```
同夸克方式，复制完整 Cookie 即可
```

**阿里云盘**
```
建议使用 refresh_token：
1. 登录阿里云盘网页版
2. 从 localStorage 或登录接口响应中获取 refresh_token
3. 在「手动添加」中，Cookie 字段填 refresh_token
```

## 五、常见问题

### Q1: PanSou 显示离线

```bash
# 检查容器
docker compose logs pansou

# 检查网络连通（从 core-server 容器内）
docker compose exec core-server wget -qO- http://pansou:8888/api/health
```

常见原因：
- 国内服务器无法访问 Telegram（需配置代理）
- 插件未启用（检查 `ENABLED_PLUGINS`）

### Q2: 转存失败

可能原因与对策：

| 错误 | 原因 | 对策 |
|---|---|---|
| Cookie 已失效 | 账号登出或换设备 | 重新扫码绑定 |
| 分享链接已失效 | 分享被取消或过期 | 换一个资源 |
| 需要提取码 | 未填或填错 | 补上提取码 |
| 请求过于频繁 | 触发网盘风控 | 降低转存频率，或更换账号 |

### Q3: 播放卡顿 / 无法播放

1. 检查「系统设置」中的播放模式
   - `直链`：最快但受网盘限速，且部分直链需要特定请求头
   - `中转`：服务端下载后转发，稳定但消耗服务器带宽
2. 对于格式不兼容的视频，启用 `HLS 转码`
3. 确认服务器上行带宽足够（1080p 约需 5 Mbps）

### Q4: 转码很慢

转码是 CPU 密集型任务：
- 降低「转码并发数」（建议 2 核 CPU 设为 1）
- 或关闭转码，改用「中转」模式 + 前端软解

### Q5: 忘记管理员密码

```bash
# 进入数据库
docker compose exec postgres psql -U postgres -d littlescholar

# 生成新密码哈希（在容器内）
docker compose exec core-server ./core-server --help  # 无此功能时用下方方式
```

最简单的方式：删除数据库重来（会丢失数据），或者用 Go 生成哈希后手动更新：

```bash
# 在本地生成 bcrypt 哈希后执行
docker compose exec postgres psql -U postgres -d littlescholar \
  -c "UPDATE users SET password_hash='<新哈希>' WHERE username='admin';"
```

## 六、备份与恢复

### 备份

```bash
#!/bin/bash
# backup.sh
DATE=$(date +%Y%m%d_%H%M%S)
mkdir -p backups

# 数据库
docker compose exec -T postgres pg_dump -U postgres littlescholar | gzip > backups/db_$DATE.sql.gz

# 配置
tar czf backups/config_$DATE.tar.gz .env docker-compose.yml

echo "备份完成: backups/db_$DATE.sql.gz"
```

### 恢复

```bash
gunzip -c backups/db_20261012_120000.sql.gz | \
  docker compose exec -T postgres psql -U postgres -d littlescholar
```

### 设置每日自动备份

```bash
# crontab -e
0 3 * * * /opt/littlescholar/backup.sh >> /var/log/ls-backup.log 2>&1
```

## 八、反向代理（HTTPS）

若需要域名 + HTTPS，在宿主机装 Nginx：

```nginx
server {
    listen 443 ssl http2;
    server_name learn.example.com;

    ssl_certificate     /etc/letsencrypt/live/learn.example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/learn.example.com/privkey.pem;

    # 前端
    location / {
        proxy_pass http://127.0.0.1:8090;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # 大文件播放
    client_max_body_size 2048m;
    proxy_read_timeout 3600s;
}
```

> **重要**：C 端播放视频时，务必让 `proxy_buffering off`，否则会导致视频加载缓慢。
