三、去重与清理

  • 去重规则：副本判据放在树的每一层 —— 同一父目录下「存在无 (N) 后缀的兄弟」时，带 (N) 的才算副本。 只看叶子名会把 Chapter (1)…(10) 这类合法分集误判成重复。结果：21 个副本子树 / 84 个叶子，637 → 352。
  • 同步策略：逐条 POST /mappings/:id/sync。全量同步是串行阻塞式，几百条必超时。
  • 同步结果：入库 6 236 条；失败 3（azw3/epub/mobi 不在后端媒体白名单）；跳过 443（file_id 已存在）。
  • 冗余清理：发现已有递归映射 #11 Magic Tree House 01-55 早已覆盖 58 个子目录 —— Register 去重键是 disk_account_id + file_id（不分映射/分类），所以新映射同步全部 skipped、表现为「映射建了但 0 资源」。 连同 3 条无媒体、1 条旧映射、1 条重复叶子，共删除 62 条冗余映射，剩 292 条。

四、已知限制

  • 纯电子书目录播不了：后端媒体白名单不含 epub / mobi / azw3（3 个目录，同步返回「没有找到可导入的媒体文件」）。
  • 搜全网结果只自动挑一个文件播放：接口返回 files 清单，但前端未提供选择入口。
  • 天翼 / 阿里云盘不支持扫码：只能用 Cookie / refresh_token（本轮未涉及）。
